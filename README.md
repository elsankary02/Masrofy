## 📱 About The Project

**Masrofy** is a personal finance management application designed to make managing money easier and more organized.

The application provides a simple and user-friendly experience that helps users monitor their financial activities, manage their transactions, and keep track of their financial goals.

## ✨ Features

- 💰 **Income Management** – Track and manage your income.
- 💸 **Expense Management** – Record and organize daily expenses.
- 📊 **Financial Overview** – Get a clear view of your financial status.
- 📋 **Transaction History** – Keep track of your financial transactions.
- 🎯 **Financial Goals** – Manage and monitor your financial goals.
- 🤝 **Debt Management** – Keep track of your debts.
- 🌙 **Dark & Light Mode** – Choose your preferred appearance.
- 🌍 **Localization** – Support for multiple languages.

## 🛠️ Built With

- [Flutter](https://flutter.dev/) – Cross-platform UI framework.
- [Dart](https://dart.dev/) – Programming language.
- Material 3 – Modern user interface design.
- Easy Localization – Application localization.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android Emulator or Physical Device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/elsankary02/Masrofy.git
```

2. Navigate to the project directory:

```bash
cd Masrofy
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
